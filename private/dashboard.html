Pantheon Hosting & Network Architecture Guide

This 3D printer monitoring system is configured for seamless deployment to Pantheon WebOps Hosting while communicating with your local network printers (192.168.1.124 and 192.168.1.36).

1

Deploying to Pantheon

Your repository already includes pantheon.yml and index.php. To push this to your Pantheon site:

# 1. Initialize git if needed
git init
git add .
git commit -m "Deploy 3D Printer Monitor to Pantheon"

# 2. Add your Pantheon Git remote (found in your Pantheon Dashboard)
git remote add pantheon ssh://codeserver.dev.{site-uuid}@codeserver.dev.{site-uuid}.drush.in:2222/~/repository.git

# 3. Push to Pantheon Dev environment
git push pantheon master
2

Understanding Local IP Access from Cloud Sites

When this web app is opened on your computer in your web browser, your browser is on the same local Wi-Fi / Ethernet network as your printers (192.168.1.124 and 192.168.1.36).

The browser sends HTTP/WebSocket requests directly from your machine to the printer IPs on port 7125 or 80.

3

Configuring Moonraker CORS (One-Time Setup)

To allow your Pantheon site to control your Klipper/Moonraker printer without browser CORS rejection, add your Pantheon URL or a wildcard to moonraker.conf:

[authorization]
cors_domains:
    *://*.pantheonsite.io
    https://*.pantheonsite.io
    http://*.pantheonsite.io
    http://localhost:*
    http://127.0.0.1:*

Then restart Moonraker (sudo systemctl restart moonraker or restart through Mainsail/Fluidd).

4

Monitoring from Outside Home (Remote Access)

If you want to view your printers on Pantheon when you are away from home, you can enter a public Tunnel URL (Cloudflare Tunnel, Tailscale Funnel, or Ngrok) in the Settings modal. The app will automatically connect to your tunnel!

How to Enable Direct Camera Stream in Google Chrome

Because this dashboard is hosted on Pantheon with HTTPS, Google Chrome blocks direct local HTTP video streams (http://192.168.1.124/...) by default under its Insecure Content (Mixed Content) policy.

1

Click the Tune / Settings Icon in Chrome's Address Bar

At the top left of Google Chrome, directly to the left of the URL https://dev-nexus3-d.pantheonsite.io/, click the Tune / Padlock icon.

2

Open "Site Settings"

Click on Site settings from the menu that appears. A new Chrome settings tab will open.

3

Set "Insecure Content" to ALLOW

Scroll down to the Insecure content permission row and change the dropdown from Block (default) to Allow.

4

Reload the Dashboard Tab

Return to this dashboard tab and click Reload. The live 30 FPS camera feed will immediately play directly inside Chrome!
